Good to know

What changes the storage you need

Compression

H.265 needs roughly half the space of H.264 for the same picture, so the same drive keeps footage for longer.

Motion recording

Recording only when there is movement can cut storage a lot. Set the activity level to how busy the scene is.

Overwriting

When the disk is full, the recorder overwrites the oldest footage. The drive is sized with 10% spare space for this.
